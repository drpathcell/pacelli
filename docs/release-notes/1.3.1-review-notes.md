No account is required — tap "Continue as guest" on the welcome screen and the
app is fully usable.

This is a bug-fix release. Feedback submitted through Settings -> Send feedback
was being encrypted with a key held only on the sender's device, so it could
never be read. It is now encrypted (X25519 + AES-GCM) to a public key in the
app, readable only by the developer.

To test: Settings -> Send feedback -> choose a type, type a message, optionally
add an email address, tap Send feedback. A confirmation appears.
