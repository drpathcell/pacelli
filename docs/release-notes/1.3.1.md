Fixes feedback.

If you sent us a message through Send feedback before now, it never reached us
in a readable form — it was encrypted with a key that only ever existed on your
own phone, so nobody could open it, us included. That's fixed. Feedback is now
encrypted so that only we can read it, and you can add an email address if
you'd like a reply.

Sorry to anyone who wrote and heard nothing back. We weren't ignoring you.
