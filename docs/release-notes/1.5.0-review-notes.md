No account is required — tap "Continue as guest" on the welcome screen and the
app is fully usable.

This release adds an optional Face ID / passcode lock on the app itself, plus
in-place editing of checklist items.

To test the lock:
1. Settings -> Privacy -> turn on "Require Face ID".
2. Switch to another app, then return to Pacelli. The content is covered and
   authentication is requested automatically.
3. A failed or cancelled authentication leaves the content hidden. A successful
   one returns you to the app.
4. Turning the setting back off requires authenticating first — this is
   deliberate, so that someone holding an already-unlocked device cannot simply
   disable the lock.

Please note: the "Require Face ID" row is hidden on any device that cannot
evaluate a biometric or passcode policy. If the test device has no passcode set
and no enrolled biometry, the setting will not appear at all. This is
intentional — enabling a lock that the device cannot satisfy would leave the
user unable to open their own data.

To test checklist editing:
1. Checklists -> create a checklist -> add an item with a quantity.
2. Tap the item's name or quantity text and edit it in place. The change is
   saved when the field loses focus, when you leave the screen, or when the app
   goes to the background.

Implementation note for review: the lock is applied to the app's interface, not
to the encryption keys themselves. The keys must remain readable without user
presence because the Notification Service Extension decrypts notification
titles on-device while the app is not running (see the 1.4.0 review notes).
