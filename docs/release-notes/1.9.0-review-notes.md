No account is required — tap "Continue as guest" on the welcome screen and the
app is fully usable.

This release has no new screens. It changes three behaviours.

To test:

1. Live photos. Tasks -> create a task -> open it -> Photos -> the dashed + ->
   "Choose from library" -> pick an image -> Done. The thumbnail appears, and
   the "arriving" label under it clears by itself once the upload finishes,
   without leaving the screen or pulling to refresh. Previously that label
   stayed until the screen was closed and reopened.

2. Account deletion. Settings -> Danger zone -> "Burn all data". The flow is
   unchanged and still deletes the account, its data and its encryption keys,
   and returns to the welcome screen. What changed is that it no longer removes
   OTHER members of the same household: if two accounts share a household and
   one deletes itself, the other keeps their household and its contents. This
   can only be seen with two accounts, so it is not reproducible on a single
   device.

3. Pairing-code clipboard. Settings -> Connect an AI -> name it -> Create ->
   tap the copy button. The code is on the clipboard as before; it is now given
   the same ten-minute expiry as the code itself, so it does not remain
   pasteable after it has stopped working.

Notes for review:

- Account deletion remains available to every user, on every account type,
  including guest accounts, and is not restricted or gated in any way. The
  change in point 2 narrows what one account's deletion does to OTHER people's
  data; it does not narrow what a user can delete of their own.

- No new permissions are requested, no new data is collected, and nothing new
  is sent anywhere. The app remains end-to-end encrypted.

- The screenshots are unchanged from 1.8.0 because no screen in this release
  looks different.
