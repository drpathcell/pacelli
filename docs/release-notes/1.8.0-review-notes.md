No account is required — tap "Continue as guest" on the welcome screen and the
app is fully usable.

This release adds photos: attaching them, seeing them, and finding them.

To test:
1. Tasks -> type a name -> tap + to create a task, then open it.
2. Scroll to Photos and tap the dashed +. Choose "Choose from library", pick
   any image, tap Done. The thumbnail appears on the task immediately.
3. Search tab -> the "Photos" segment at the top. The photo is there with the
   task's name underneath. Tap it to see it full screen; tap Done to go back.
4. Checklists -> create a list and an item -> swipe the item right and tap
   "Photo" to attach one. It then shows as a small thumbnail in the row.
5. Settings -> Photos shows how much space they take on the phone, with
   "Free up space" and "Read photos again for search".

Notes for review:

- Choosing from the library uses the system photo picker, which reads the
  chosen image without the app being granted access to the library. That is why
  no photo-library permission is requested. Only the camera asks.
- The picture itself is encrypted on the device before it is stored, and the
  encrypted copy is the only thing that leaves the phone. A readable copy stays
  in the app's own Documents folder, which is visible in the Files app so the
  user can take their photos out or delete them. That folder is deliberately
  excluded from iCloud backup.
- Location metadata is removed from every photo before it is stored, and images
  are re-encoded to a maximum of 2048 pixels.
- Text recognition runs on the device using the Vision framework. No image and
  nothing read from an image is sent anywhere for processing.
- A photo shown as "arriving" is one whose upload has not finished; the small
  version is already visible to everyone. Nothing is lost if the upload is
  interrupted.

No new data is collected and nothing is shared with us. The app remains
end-to-end encrypted; the "Privacy & encryption" screen in Settings has been
updated to describe exactly how photos are handled.
