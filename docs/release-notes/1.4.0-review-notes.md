No account is required — tap "Continue as guest" on the welcome screen and the
app is fully usable.

This release adds push notifications for household activity, off by default.

To test:
1. Settings -> Reminders -> turn on "Task reminders" (iOS will ask for
   notification permission; tap Allow), then turn on "Tell me when someone
   adds a task".
2. A second person in the same household adds a task. Their device sends
   nothing directly; a Cloud Function sends the notification.
3. The notification names the task.

Implementation note for review: the app is end-to-end encrypted, so the server
cannot read task titles. The encrypted title is carried in the APNs payload and
decrypted by a Notification Service Extension on the receiving device, which
reads the household key from a shared keychain access group. If decryption is
not possible the notification shows generic text ("A new task was added to your
household") rather than failing.
