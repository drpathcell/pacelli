No account is required - tap "Continue as guest" on the welcome screen and the
app is fully usable.

This release changes how a shopping-list row is laid out and adds a total.

To test:

1. Checklists tab -> open or create a checklist -> add an item with a long
   name (for example "Extra large family pack of wholegrain breakfast cereal
   with dried fruit"). The name now wraps onto several lines instead of being
   truncated. Return still finishes editing.

2. Prices and the total appear only for items that carry a shelf price, which
   are added by a household's connected AI assistant from a supermarket
   catalogue (Settings -> Connect an AI, introduced in 1.7.0). Reviewers will
   not see prices without such an assistant, and a list without prices looks
   exactly as before apart from the wrapping in step 1.

Notes for review:

- No new permissions, no new data collected, no purchases. The prices are
  retailer shelf prices captured when the item was added, shown for the
  household's own budgeting, and labelled as estimates.

- The screenshots are unchanged from 1.11.0.
