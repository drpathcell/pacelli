No account is required — tap "Continue as guest" on the welcome screen and the
app is fully usable.

This release adds "Connect an AI": a way to give an external AI tool access to
your own household data, and to take it away again.

To test:
1. Settings -> Household -> Connect an AI.
2. The list is empty on a new household. Type a name in the field at the
   bottom and tap "Create a pairing code".
3. An eight-character code appears with a ten-minute countdown, a copy button
   and an explanation. That is the whole user-facing flow — redeeming the code
   happens in whatever AI tool the user is configuring, outside the app.
4. Tapping "Create another code" mints a second, independent one. Waiting for
   the countdown to reach zero makes the code disappear rather than leaving a
   dead string on screen.

Notes for review:

- Nothing is provisioned when a code is created. The assistant only becomes a
  household member when the code is used, so an abandoned code leaves nothing
  behind. This is why the "Connected" list stays empty during the steps above.
- The code is single-use and expires after ten minutes, server-side. It is
  never written to disk on the device.
- An assistant is a separate member with its own identity. It does not use, and
  never receives, the user's own credentials, so disconnecting one has no
  effect on the user's account.
- Disconnecting revokes the assistant's session and deletes its copy of the
  household key before removing it, so access ends immediately rather than
  when its current token would have expired.

No new data is collected and nothing is shared with us. The privileged part of
pairing runs in the app's own Firebase backend so that no administrative
credential is ever placed on a phone.

The app remains end-to-end encrypted. This release also encrypts checklist and
plan item quantities on the device before storing them; the "Privacy &
encryption" screen in Settings has been updated to match.
