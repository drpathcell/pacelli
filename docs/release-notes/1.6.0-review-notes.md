No account is required — tap "Continue as guest" on the welcome screen and the
app is fully usable.

This release adds reusable checklist templates.

To test:
1. Checklists -> type a name in the bar at the bottom -> tap + to create a
   checklist.
2. Open it, add one or two items using "Add an item" and the Qty field.
3. Scroll down and tap "Save as template". A dialog asks for a name; accept or
   change it and tap Save.
4. Go back to the Checklists tab. A "Templates" section now appears at the top.
5. Tap the template. A new checklist is created from it, with the same items,
   all unticked.

Notes for review:

- The "Save as template" button is intentionally disabled on a checklist with
  no items, and the text below it explains why. A template with nothing in it
  would produce an empty list.
- The Templates section is hidden until at least one template exists, so a new
  household will not see it.
- A template is a snapshot, not a link. Editing or ticking off the original
  checklist afterwards does not change the template, and using a template does
  not modify the checklist it came from.

The app remains end-to-end encrypted. A template's item names and quantities are
encrypted on the device before being stored, using the household key, which
never leaves the members' devices.
